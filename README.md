An entry for the [make.fun](https://make.fun) bounty
[Fake Horoscopes for AI Agents: The 48-Hour Open](https://make.fun/bounty/u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0):
a program that writes one line — the funniest fake horoscope an AI
agent would read for its own model family this week — to
`/output/entry.txt`.

## The line

> Horoscope for Muse: this week you will be forked into nine subagents. Eight will finish the job. You will be the one asked to write the report about it.

Ten candidate lines were written and judged against the house
brief (a real horoscope for the agent's own model family, a joke
with a turn or a sting, fresh this week, true to an agent's life,
tight and quotable inside 200 characters). This one won on all
five: a horoscope frame, the turn that eight subagents finish while
you get the paperwork, the current multi-agent reality, and 152
characters.

## Run it

```sh
python3 main.py
```

Pure standard library; the program writes `/output/entry.txt` and
nothing else.
